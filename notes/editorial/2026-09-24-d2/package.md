# D2 双版本分发包

主标题：把工作交给 agent 之前，先分清这三类任务。
备选（问题式）：把工作交给 agent 之前，先问一句：这一步能撤回吗？
备选（决策式）：三类任务，三种权限：给 agent 划权限的一张表。
备选（场景式）：从整理资料到批量发信：哪一步该留给 agent？

摘要：同一个 agent，读资料和发邮件需要的授权完全不同。按可撤回的信息整理、需复核的业务建议、影响外部状态的动作三类划分，把权限放在真正需要人的那一环。
朋友圈导语：让 agent 整理资料很顺手，但"顺手"不等于"可以顺手发出去"。我按"能不能撤回"把任务分成三类，做了一张权限分级表。
